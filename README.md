# QA_GURU_HW_2

## Описание
Проект для сдачи домашнего задания "Погружаемся в инструментарий и библиотеки". 

Цель данного задания — создание простого проекта с использованием Selenium WebDriver 
для тестирования веб-приложений. Необходимо создать два теста, проверяющих успешное открытие страниц 
Google и GitHub.

▌ Шаги выполнения задания:

1. Регистрация аккаунта на платформе GitHub.
2. Создание нового проекта.
3. Написание теста, проверяющие открытие страниц:

   - Страницы https://www.google.com/
   - Страницы https://github.com/

4. Проверка работы тестов и исправление возможных ошибок согласно стандартам Python (PEP8, PEP20).


▌ Итоговая структура проекта:

- tests.py: файл с написанными вами тестами на открытие указанных страниц.
- utils.py: файл с функциями, используемыми в тестах и отформатированными согласно стандартам оформления кода.
